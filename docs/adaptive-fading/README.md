# Gradual fading from a fresh start

Running seven fresh scheduled-fade fits and seven matched unfaded controls.
Exactly unfaded at update0; calibrated weak fading at update100; continuous
geometric reduction to1s/1oct by update2000; then patience up to update3000.

[Protocol](protocol.md) · [Qualification](qualification.json)

No saved plateau or previously fitted state is used. Results will report both
the best common unfaded-loss checkpoint and the actual last iterate.
